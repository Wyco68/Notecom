How Notecom works

From lecture slides to notes you can search, in one command.

Notecom turns a PDF or a slide deck into plain-language study notes, filed under the right subject, and kept in one shared library your classmates can read too. This page walks through how that actually happens, step by step.

The one rule

Every copy of Notecom reads the same notes. Only one kind can write new ones.

Writing a note runs your own Claude Code CLI, on your own Claude subscription. That only works on the machine the CLI is actually signed in on — so a shared, teacher-run server can show every note perfectly, but it can't write new ones for you.

Step by step — writing a note

How a lecture file becomes a note

Nothing gets invented. Claude reads the file you gave it and writes only what's in there, in clearer words.

  1. 1
    You hand over a file. A lecture PDF, slide deck, or photo of a whiteboard — dragged into the terminal, or dropped on the Generate button in the app.
  2. 2
    Claude reads it and writes the note. Plain, high-school-level sentences, with the technical terms kept exactly right — grounded only in what's on the page, nothing added from memory.
  3. 3
    The note is saved to vault/, on your machine. One file per note, filed under the subject folder, with its place in the list recorded alongside it.
  4. 4
    The app picks it up and stores it for good. Next time the note list loads, Notecom copies the new file into Supabase — the shared library everyone actually reads from.

Step by step — reading a note

What happens when you open the app

There's no separate sync step to wait for. Every device asks Supabase directly, every time — so a note written on your laptop shows up on your phone the next time you open it there.

Search works the same way: typing in the sidebar box asks Supabase to rank the note sections that match, and only the ones you're allowed to read come back.

Underneath

Three things worth knowing

Folders, not files

Sharing is per subject

You share a folder, not a single note. Everything inside it — every note, every quiz — opens for whoever you add, with the role you gave them: viewer or editor.

Deletes don't vanish

Removed, not erased

Deleting a note marks it removed instead of dropping the row. That way the app can always tell "gone" apart from "never existed" — which matters once several people share a folder.

No hidden costs

Your subscription, nothing extra

Writing a note spends nothing beyond the Claude subscription you already have. Notecom holds no API key of its own and never bills anyone on your behalf.
